About The Project

A unified collection of highly resilient, automated Python scrapers designed to run continuously in GitHub Actions. This project extracts real-time statistics (followers, subscribers, coding metrics, etc.) across various platforms and outputs them as clean JSON data.

The primary purpose of this repository is to automate the updating of social media and platform statistics on personal websites or portfolios, providing a convenient alternative to requiring authorized API access from each individual platform.

Disclaimer: We do not promote unauthorized web scraping, hacking, or any illegal acts under the IT Act. Please use these scripts responsibly and strictly within fair usage policies.
